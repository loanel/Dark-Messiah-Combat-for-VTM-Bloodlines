# Dark Messiah Combat for VTM Bloodlines
This is a modification for Vampire: The Masquerade - Bloodlines that replaces the default melee combat system with first person combat from Dark Messiah of Might and Magic. It was created using Claude Code and general knowledge contained in the universal-modder repository. It reuses the game's existing models (the arms, hands and clothing of each clan in every outfit, and the melee weapons themselves) to create the first person view for all melee weapons available in the game.

This mod is possible only because of the hard work by the developers of the **[Unofficial Patch v12.0](https://www.moddb.com/mods/vtmb-unofficial-patch)**, which not only fixes the base game in multiple ways, but also provides the Game Mod Loader that runs this mod's plugin, and the Bloodlines SDK whose tools build the mod's models.

In the repository you will find:
- scripts that convert all necessary assets and logic from both Dark Messiah and VTM: Bloodlines (with the Unofficial Patch installed); no game files are present in the repository, only the scripts that work on games installed by the user
- various documents in the docs directory that explain how this was achieved, including all steps taken by Claude Code, directions on how to handle problems, and a general description of the sessions and prompts
- a release of the mod that contains a pre-built dmcombat.vtm - the plugin necessary for the mod to work; below you will also find a description of how to build it yourself

I am aware that using AI is a very grey area when it comes to games, however it has now been 15+ years since I played this game for the first time and we are still stuck with the atrocious melee combat system. It has come to the point that everyone ALWAYS recommends to just play guns or Tremere with blood magic. I feel that this mod makes it actually fun to play melee weapons. # Claude Description:
Dark Messiah of Might and Magic's first-person melee combat for **Vampire: The Masquerade - Bloodlines** with the
**[Unofficial Patch v12.0](https://www.moddb.com/mods/vtmb-unofficial-patch)**.

**Version 0.1** - the first release. Expect rough edges; bug reports and suggestions are welcome.

- You see your own character's arm in first person, swinging the weapon with Dark Messiah's animations.
- Fast-attack chains and directional power attacks, timed parries on the right mouse button, an adrenaline meter and
  finishing moves.
- All 11 player melee weapons, on the arm of your own character and outfit.
- Hits still use Bloodlines' own dice, stats and weapon requirements.

This repository contains no files from either game. The installer builds everything from **your own copies** of both
games, on your PC.

## Requirements

Install these first:

1. **Vampire: The Masquerade - Bloodlines** (Steam or GOG) with the **[Unofficial Patch v12.0](https://www.moddb.com/mods/vtmb-unofficial-patch)**. Dark Messiah Combat checks the
   exact game builds and stays off with any other version.
2. **The Bloodlines SDK**, installed into the game folder (its tools end up in `<Bloodlines>\SDKBinaries`). The
   installer uses its model compiler and texture tool. The SDK is available on the
   **[Unofficial Patch's ModDB page](https://www.moddb.com/mods/vtmb-unofficial-patch)** (Downloads section).
3. **Dark Messiah of Might and Magic** (single player, Steam or GOG). Its animations, arm and one sound are read from
   your copy.
4. **Python 3.8 or newer** (python.org or the Microsoft Store) with **numpy** and **Pillow**:
   `python -m pip install numpy pillow`.

**Offline:** nothing in this repository downloads anything or connects to the internet. The installer only reads your
game installs and writes into this folder and your Bloodlines folder.

## Install

1. Download the latest release and unpack it **into your Bloodlines folder**, so you get
   `<Bloodlines>\DMCombat\install.bat`. (The release includes the ready-built plug-in, `bin\dmcombat.vtm`.)
2. Close the game and run `install.bat`. If Bloodlines is in a protected folder (Steam's default under
   `C:\Program Files (x86)`), right-click `install.bat` and choose **Run as administrator**. About 250 MB of free space
   is needed for the build.

It checks everything above, finds Dark Messiah through Steam or GOG (or asks; or run
`install.bat --dark-messiah "<folder>"`), builds the models, textures and data (about a minute) and installs them into
the Unofficial Patch. It replaces 11 melee item files and 2 keybind default files; the originals are kept in
`DMCombat\backup` and every installed file is listed in `backup\install_manifest.json`.

- **Uninstall:** `install.bat --uninstall` removes everything and restores the original files.
- **Repair** (after a game or patch update): run `install.bat` again.

## Playing

Start Bloodlines the way the Unofficial Patch is always started: its desktop shortcut, which runs
`Vampire.exe -game Unofficial_Patch`. From Steam, add `-game Unofficial_Patch` to the game's launch options
(Properties > Launch options). Started without the patch, the game runs without Dark Messiah Combat.

- **Left mouse:** attack. Tap for the fast chain; hold for a power attack, aimed by the movement key (W/A/S/D) held when
  it starts. With the adrenaline meter full, a released power attack becomes a finishing move. The direction is read
  from the physical W/A/S/D keys, whatever your movement keybinds are.
- **Right mouse:** block / parry (a block just before the hit is a perfect parry). While holding a power attack, it
  re-aims the attack with the movement key held at that moment.
- **Q:** cast the selected discipline. The installer moves "Cast Discipline Power" from the right mouse button to Q;
  change it in Options > Keyboard like any other key.
- Melee weapons stay in first person.
- Settings: `dmcombat.ini` in the game folder, reloaded while the game runs. Log: `dmcombat.log`.
- If the game process stays open after you quit (it happens on some systems), set `exit_watchdog=1` in `dmcombat.ini`:
  the process then ends itself 5 seconds after its window closed.

### Damage

Every hit is still decided by Bloodlines itself, exactly as without the mod: the game rolls your attack (the weapon's
lethality and your Melee dice, minus the weapon's skill requirement) against the enemy's soak and defence. Dark Messiah
Combat then multiplies the damage of that hit by the move that landed it:

| Move | Damage | Adrenaline per landed hit |
|---|---|---|
| Fast attack (tap) | 0.75 x | 0.5 |
| Power attack (hold) | 2.5 x | 3 (the right-hand slash: 1) |
| Adrenaline move (power attack with a full meter) | 7.5 x | - |

- `damage_scale` in `dmcombat.ini` multiplies all of it (default 1.0).
- Power attacks and adrenaline moves always knock the enemy back and break their guard: the dice can't turn them into
  a block or a dodge.
- A weapon whose skill requirement is above your Melee still works, but hits weaker (the game's own rule).

### The three power attacks

Hold the left mouse button; the movement key held when the wind-up starts picks the attack:

1. **Side slash** (A or D): a horizontal cut that staggers enemies sideways (`side_knock` in `dmcombat.ini`: 2 = big
   stagger, 0 = straight back). Both do the same damage; the right-hand slash (D) gains less adrenaline.
2. **Thrust** (W or S): a stab with the longest reach of the power attacks (30 units past the blade tip, slashes 20).
3. **Power slash** (no movement key): Dark Messiah's straight heavy cut, knocking the enemy straight back.

### Adrenaline and the Melee skill

Landed hits fill the adrenaline meter next to the blood bar. How much it takes depends on your **Melee** skill:
20 - 2 x Melee points, never fewer than 8.

| Melee | 0 | 1 | 2 | 3 | 4 | 5 | 6+ |
|---|---|---|---|---|---|---|---|
| Adrenaline needed | 20 | 18 | 16 | 14 | 12 | 10 | 8 |

So with Melee 5 about four landed power attacks fill it; with Melee 0 it takes seven. The meter drains by 1 point
every 20 seconds. When it's full, the bar flashes, Dark Messiah's sound plays, and a red ring on the crosshair and red
screen edges pulse. The next released power attack becomes an **adrenaline move**:

- **Behead** (A): a guaranteed 7.5 x blow on the enemy in front of you, then the swing cleaves through anyone else in
  its path.
- **Impale** (W or S): a guaranteed 7.5 x thrust through the enemy in front of you, with the longest reach of all.
- **Huge combo** (D or no key): two sweeping strikes at 7.5 x.

A strong enemy can survive an adrenaline move. The requirement, gain, drain and range are all in `dmcombat.ini`
(`adrenaline_base`, `adrenaline_per_melee`, `adrenaline_min`, `adrenaline_gain`, `adrenaline_decay`, `finisher_range`).

## Building the plug-in yourself

The release includes `bin\dmcombat.vtm`. To build it from `src\dmcombat`: Visual Studio 2017 or newer (or its Build
Tools) with "Desktop development with C++", then run `build.bat` from a path without spaces (for example a drive letter
mapped with `subst W: "<Bloodlines>\DMCombat"`). Run `python tools\weapon_prep.py` and `python tools\build_arms.py`
first (or the installer once): they write two generated headers the plug-in includes.
